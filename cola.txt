## escada
De baixo pra cima. Cada degrau só faz sentido se o de baixo está ok.

 0. sintoma      ping -c2 site.lab · curl -v http://site.lab/      a mensagem EXATA diz o degrau
 1. link         ip -br link                     UP? LOWER_UP? NO-CARRIER?
 2. IP           ip -br addr                     tem IP? é o da topologia? máscara?
 3. rota         ip route                        tem default? o gateway está na minha rede?
                 ip route get 10.0.0.10          qual rota esse destino usa
 4. vizinho      ping <gateway> · ip neigh       o próximo salto responde ARP? (FAILED = ninguém)
 5. caminho      traceroute -n X · mtr -n X      até onde chega? onde perde?
 6. nome         cat /etc/resolv.conf            quem é meu DNS?
                 dig site.lab                    o que o DNS responde
                 getent hosts site.lab           o que o SISTEMA resolve (inclui /etc/hosts)
 7. porta        nc -zv -w2 10.0.0.10 80         abre? recusa? fica mudo?
                 ss -tlnp  (no servidor)         quem escuta e EM QUE IP
 8. filtros      nft list ruleset · tc qdisc show    alguém bloqueando? perda artificial?
 9. pacote       tcpdump -ni eth0 icmp           o que passa de fato, em cada nó

Num roteador: sysctl net.ipv4.ip_forward (1 = repassa pacotes)
Temas: cola erros · cola tcpdump · cola consertar

## erros
nomes (ping, curl, qualquer programa)
  Falha temporária na resolução de nome   o DNS NÃO RESPONDEU (fora do ar, inalcançável, rede caída)
    (Temporary failure in name resolution)
  Nome ou serviço desconhecido            o DNS RESPONDEU: esse nome não existe (NXDOMAIN)
    (Name or service not known)
ping (aqui ele fala português; entre parênteses, o original)
  A rede está fora de alcance     o PRÓPRIO host não tem rota. nem saiu pacote
    (Network is unreachable)
  Host de destino inalcançável    (De <seu IP>) ARP do próximo salto falhou
    (Destination Host Unreachable)  (De <um roteador>) aquele roteador não sabe seguir
  100% loss, sem mensagem         morreu calado: firewall drop, rota de VOLTA, host fora
  Mensagem muito longa            pacote maior que a MTU da SUA placa (ou de um salto
    (Message too long / Frag needed)  que avisou com ICMP)
  Não há espaço de buffer disponível  no laboratório: o pacote é maior que a MTU da
    (No buffer space available)       placa do OUTRO lado do cabo. num cabo de verdade
                                      ele só some, sem mensagem
curl / nc
  Could not resolve host          DNS ou /etc/hosts. a rede pode estar perfeita
  Connection refused (na hora)    chegou! ninguém escuta ali, ou firewall com reject
  timed out / fica girando        SYN sem resposta: drop, rota, host fora
  conecta e trava no meio         MTU (pacote pequeno passa, grande não)
dig
  NOERROR + ANSWER                resolveu
  NXDOMAIN                        o nome não existe naquele DNS
  timed out / no servers          o DNS não responde (endereço errado? rede?)
mtr / traceroute
  * * * num salto e depois volta  aquele roteador só não responde ICMP. ignore
  perda que começa e vai até o fim    perda real, a partir daquele salto

## tcpdump
  tcpdump -ni eth0                tudo na eth0 (-n: sem traduzir nomes)
  tcpdump -ni any icmp            ping em qualquer interface
  tcpdump -ni eth0 host 10.0.0.10 and port 80
  tcpdump -ni eth0 arp            quem pergunta quem tem tal IP
  tcpdump -c 10 ...               para depois de 10 pacotes
  tcpdump -e ...                  mostra os MACs
Ler:
  [S] sem [S.] voltando           SYN sem resposta
  [S] e depois [R.]               recusado
  request sem reply               olhe a rota de volta / firewall do outro lado
  who-has X sem reply             ninguém com o IP X neste enlace
Dica: deixe um ping rodando em segundo plano antes
  ping 10.0.0.10 >/dev/null &     (e depois: kill %1)

## consertar
  ip link set eth0 up | down
  ip addr add 192.168.1.10/24 dev eth0 · ip addr del ...
  ip route add default via 192.168.1.1
  ip route replace default via X  (troca ou cria)
  ip route del default
  sysctl -w net.ipv4.ip_forward=1
  nano /etc/resolv.conf · nano /etc/hosts
  nft list ruleset · nft flush ruleset (apaga TODAS as regras)
  nft -a list ruleset + nft delete rule inet <tabela> <chain> handle N
  tc qdisc del dev eth0 root
  ip link set eth0 mtu 1500
